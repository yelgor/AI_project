# Приклади результатів

Ці ZIP створені автоматичними перевірками конструктора; це маленькі
демонстраційні набори, а не навчальна вибірка для GPR чи real-world дані.

- demo-grid.zip: 6 просторових позицій на двох висотах у кімнаті.
- demo-husky.zip: 6 вимірювань антени Husky під час руху, з world pose,
  quaternion, sim time та швидкостями.

Кожен архів містить scenario.json, manifest.json, measurements.csv,
measurements.jsonl, events.jsonl. Формат і одиниці — docs/DATASET_GUIDE.md.
