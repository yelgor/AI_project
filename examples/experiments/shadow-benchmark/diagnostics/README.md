# Діагностичні спроби, виключені з curated benchmark

Це журнали ітерацій, а не додаткові незалежні успіхи основних серій.
Підсумки експериментів збережені без зміни їх початкових статусів; поле
`valid_for_curated_benchmark` у wrapper пояснює виключення.

- `081643…`: недійсні формальні успіхи через усереднення всієї seed-історії
  за availability-time; raw сигнал лишався слабким. Регресія виправлена.
- `082241…`: попередній частковий контроль із readiness failure.
- `082618…`: коректний контроль 4/4, обмежений простим світом; основна серія
  пізніше перевіряє більше умов і не додає ці повтори до своїх знаменників.
- `083507…`: перерваний прогін, що виявив integer-zero ROS serialization crash.
- `084042…`: розширена діагностика GPR-zero та checkpoint reset; усі її
  завершені спроби/причини збережені у summary. Окремі GPR-zero ZIP дозволяють
  переглянути довге блукання. Ця серія була зупинена, а не оголошена 140 тестами.

Десять коректних повних B1 source-місій із останньої діагностики використані
як спільні історії основних серій; вони є в `sources/` основних архівів,
із початковими IDs/версіями. Події після втрати не навчають paired recovery.
