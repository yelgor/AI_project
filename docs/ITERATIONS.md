# Перевірені ітерації

Дата перевірки: 25 жовтня 2026. Звіти старих спроб збережені окремо в
`examples/experiments/shadow-benchmark/diagnostics/`; вони не входять у новий
підсумковий benchmark і не видаються за коректне навчання.

| Ітерація | Спостереження | Зміна / перевірка |
| --- | --- | --- |
| Старий сценарій | Втрата на межі видимості не гарантує помітного повернення | Окрема ціль за перешкодою для кожної сцени |
| Перенесення історії | 4 формальні успіхи з рухом <0.01m: raw RSSI ~−60dBm, але monitor ~−29dBm | Виявлено помилку: усі seed-покази отримували один availability-time; вікно переведено на фізичний measurement-time. Ці 4 успіхи недійсні |
| Вибір цілі | Одна позиція: ~−63dBm у простому світі, ~−46dBm в офісі | Перевірено центр і 4 сусідні точки; 10 окремих зон із запасом 9–24dB нижче −47dBm. Oracle-покази не навчають policy |
| Чотири парні повернення | 4/4 успіхи, медіана 6.117m / 16.15sim-s | Підтверджено реальний рух; Wilson95 [0.510,1.000], тому це контроль працездатності, не перевага методу |
| Зміна світу | ROS native serializer аварійно завершував процес на integer-zero Vector3 | Явне float перед serialization, ROS regression test і фактичний cold перехід shadow→office |
| Підготовка | Повторні сцени не потребують нового Gazebo/опису Clearpath | Warm GZ pose reset, epoch/revision fences, reuse RF-worker; окремі execution profiles у кожному trial |
| Обсяг даних | CIR payload великий, але для recovery потрібні RSSI/поза/рішення | Опційне збереження CIR; coherent power усе одно обчислюється за всіма шляхами |
| Навчальні точки | Python spatial thinning на 150 точках: ~12.7ms у локальній мікроперевірці | Векторизований добір: ~1.5ms; regression test звіряє той самий набір із cap150 |
| Демонстрація | Безперервний software WebGL забирав CPU навіть для незмінної сцени | Render при зміні даних/камери; браузерна перевірка повного запуску однією кнопкою пройшла |
| Офіційний Husky | STL втрачав face materials, роблячи колеса жовтими | Збережені original Clearpath COLLADA materials; геометрія, URDF transforms і реальні joint states |
| Складність | Потрібні сцени з кімнатами, металевими стелажами, проїздами та двором | 10 повних вихідних B1-місій: 10/10, NLOS-підтвердження у всіх; повернення 3.78–6.11m |

Підсумки серії 140, spatial reference й offline-підбір параметрів див.
`examples/experiments/shadow-benchmark/README.md`. Час мікроперевірки thinning
не є прискоренням усієї симуляції. Невдалі/перервані підготовчі спроби збережені,
а нові версії запускалися окремими серіями.

Для наступної ітерації потрібні нові незалежні геометрії, контрольні недосяжні
маршрути, convergence/матеріальна калібровка та повтор фізичного порівняння
після вибору hyperparameters на train/validation. Поточні test-світи після
аналізу стають відомим benchmark і більше не є недоторканим holdout.
